# PARKVIEW — GitHub Pages package

This folder is the ready-to-publish website. Upload the files in this folder to the **root of your GitHub repository** — upload `index.html`, `assets/`, `images/`, `favicon.svg`, `robots.txt`, and `.nojekyll` directly. Do not upload the outer ZIP folder as a nested folder.

## Publish on GitHub Pages

1. Create a GitHub repository. It can be named `yourusername.github.io` or any other name.
2. Upload the contents of this package directly to the repository root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then click **Save**.
7. Wait a minute or two, then open the URL GitHub shows under Pages.

The site uses relative asset paths, so it works on both:
- `https://yourusername.github.io/`
- `https://yourusername.github.io/repository-name/`

## Editable code

The `source/` folder contains the React/Vite source and the original project configuration. The files at the package root are the compiled version intended for direct GitHub Pages hosting.
